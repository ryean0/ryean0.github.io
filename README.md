# Ryan Phua

Static e-portfolio for [ryean0.github.io](https://ryean0.github.io/).

```bash
npm test
npm run preview
```

Preview serves the repo root at `http://127.0.0.1:4173/`.

GitHub Actions workflow `.github/workflows/pages.yml` runs the tests and deploys the static files. In the repository settings, Pages source must be **GitHub Actions**. A branch source will not publish this site.

`/anubys/` redirects to [https://anubys.dev/](https://anubys.dev/).
