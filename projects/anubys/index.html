Anubys

Anubys is a pip-installable Python framework for LLM evaluation and regression testing of AI agents. Baseline and candidate models run in simulated CI, and GitHub Actions runs 400+ pytest tests on every pull request.

Open anubys.dev All work

What it does

A merge check, with a verdict.

The check compares a candidate with a baseline on paired scenarios. The labels below are the three answers the example console uses.

  • Pass

    The gap stays inside the bar the suite set.

  • Block

    The evidence says the candidate is behind the baseline.

  • Insufficient evidence

    The interval is too wide to decide the merge.
