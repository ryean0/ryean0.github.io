Anubys

CI-native agent regression harness · anubys.dev

Problem
An LLM agent change needs a merge decision. A dashboard can score a run and keep the trace, and still leave the pull request without a statistics-backed check.
Approach
Anubys compares a candidate LLM agent to a baseline on paired scenarios in CI and returns one stats-backed merge check: Pass, Block, or Insufficient evidence.
Outcome
The check adds 0 ms in production and stops at a $38 spend cap. Status: public beta.

Campus platform

USAC Campus Events Commission Open

Oct 2023 – Jul 2025 · Los Angeles (UCLA)

Problem
The undergraduate events site had to publish daily updates for a campus of student users, while hot API paths and a long setup kept the web team slow.
Approach
Maintained and upgraded key backend features, with data preloading and caching via AWS ElastiCache, GitHub Actions for CI/CD, and Docker-Compose so dev and production environments came up in one step.
Outcome
Daily event updates for >47000 student users at UCLA. Direct database query load cut by 30-50% under peak web traffic. p95 latency on the top 5 hottest API endpoints improved by ~3x versus pre Elasticache baseline metrics. New developer onboarding went from >3.5 weeks to ~1 week.
