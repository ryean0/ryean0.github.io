Featured project

Anubys

CI-native regression harness for LLM agentic workflows

What it is
A pip-installable Python framework for LLM evaluation and regression testing of AI agents. Baseline and candidate models run in simulated enterprise CI/CD pipelines.
Method
Non-inferiority hypothesis testing with paired, scenario-level comparisons, similar to A/B testing for a new model release.
CI
GitHub Actions runs 400+ pytest tests on every pull request without exposing secrets or incurring model costs. Paid LLM runs stay in a separate workflow.
  • Python
  • pytest
  • GitHub Actions
